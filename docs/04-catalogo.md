# Bloque 4 — Catálogo en arrays

`src/06-listas.php` practica `for`, `while` y `foreach`. `src/07-catalogo.php` recorre
una lista de fichas asociativas con `id`, `title`, `artist`, `category`, `duration` y `src`.
Los ids son identificadores estables, no posiciones del array. Las categorías válidas
son `electronica`, `rock` y `bandas-sonoras`.

El catálogo inicial se devuelve desde `src/lib/catalogo-inicial.php`; el HTML escapa
los textos y contempla la lista vacía. Cambia datos, no la presentación, para probar
más fichas.
